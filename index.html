PR Streak Rankings

Longest streak of consecutive competitions with a personal record, for every WCA competitor.

Next competitions come from accepted registrations as of the last update. A streak is the most consecutive competitions a person attended where they set at least one PR (matching a PR counts). Active means they're on a PR streak right now. All-time ranks use the longest streak and active ranks use the current one. Ranks marked T- are tied. This is an unofficial fan-made tool.
